Websites change.
Anvil repairs itself.

Anvil is an agent that uses websites the way a person does. It opens the page, types, presses buttons and reads what comes back. When the website changes under it, Anvil notices, works out new steps from the live page, and keeps them only once a real result proves they work.

Here it books study rooms on a small library website. You get to change that website, and see what Anvil does about it.

    How it works, for the technical crowd

    Most self-healing tools patch a selector.
    Anvil re-derives the plan, then proves it.

    01

    Triage first

    A network blip is retried, a bot block is reported, an empty page is fine. Only a real structural change triggers a repair.

    02

    Whole-plan repair

    The model sees the goal, the old plan, what changed, and every page an attempt got stuck on, then writes every step again.

    03

    Contract gate

    The first good run teaches types, bounds and echoes. A new plan is promoted only if its result passes. Three failures roll back, honestly.

    04

    Before anything fails

    Anakin Website Monitoring watches the site. When it changes, a signed webhook starts the repair before anyone's run breaks.
